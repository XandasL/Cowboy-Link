Cowboy Link v1.1.0
Mod by XandasLegend

Cowboy Link replaces Link's classic cap with a western-style cowboy hat.

Features:
- Hero's Tunic support
- Ordon Outfit support
- Outfit toggles
- 512, 1K, 2K, 4K and Vanilla texture presets
- Original and dark leather styles
- Brightness control
- Optional custom color control
- Runtime reconstruction from the player's own local game assets
- No complete al_head.bmd or bl_head.bmd files bundled in the package

If an outfit toggle does not update immediately, change area so the game reloads
the model. If necessary, restart the game.
